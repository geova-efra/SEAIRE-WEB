SEAIRE - ADMIN ANTERIOR + PROYECTOS

Esta versión conserva el estilo del panel administrativo anterior y agrega:
- Crear proyectos
- Editar proyectos
- Eliminar proyectos
- Elegir servicio
- Ubicación
- Año
- Descripción
- Varias fotografías por proyecto
- URL de video
- Publicar / dejar como borrador

IMPORTANTE:
Esta versión utiliza localStorage, igual que el administrador anterior. Es útil para probar el funcionamiento y la interfaz.
Para que los proyectos publicados sean visibles para TODAS las personas desde cualquier dispositivo, hay que conectar este panel a una base de datos/Storage (por ejemplo Supabase) y cambiar el index.html para leer de esa base de datos.
